## 二、第一阶段主导航（克制原则）

第一阶段主导航应克制，只保留：

```text
首页
项目
素材中心
生产任务
作品库
设置
```

其余长期导航项随 Phase 推进逐步开放，不为未实现能力预留空壳入口。

设置区规划（D-016 / D-020）：

```text
设置
├── 企业信息
├── 成员与基础权限
├── AI 模型
│   ├── 平台默认模型
│   └── 企业自有 API Key（后续，BYOK）
├── Provider 连接
├── Local Agent
├── 内部用量与成本
└── 审计日志
```

设置区**不得出现**：套餐中心、支付、账单、充值、订阅管理（产品不建设面向客户的收费系统，D-016）。Provider 选择仍不进入普通运营主流程，只出现在设置/管理员配置或技术诊断区域（D-013）。MVP 不提供 Provider 设置页、模型选择器、V4-Pro 切换、BYOK 输入框或第三方中转配置；「AI 模型」的平台默认模型由服务端配置管理（D-023）。

## 五、普通运营与技术诊断页面隔离

技术页面：

```text
本地执行器
Provider 连接
诊断日志
失败证据
```

**不得与普通运营主流程混在一起**：

- 运营主导航不出现 Playwright、batch.json、executor 等技术概念；
- 技术状态（执行日志、重试次数、Provider 任务 ID、截图证据、技术状态）收敛在任务详情的次级区域与技术区页面；
- 技术区页面保留完整诊断能力，供技术与执行器管理员使用。

## 七、模板中心（规划）

模板方向：小红书护肤种草、抖音零食带货、淘宝商品讲解、本地生活探店、知识口播、企业介绍、照片说话、双人访谈。

模板可预设：内容结构、时长、视频类型、数字人、声音、背景、字幕、Provider、质检规则。

模板中心入口与模板编辑器属于长期导航，第一阶段不实现。

## 八、作品库（规划）

作品库能力：预览作品、标记通过/退回、批量下载、按商品打包、下载文案、下载封面、下载审核表、导出项目交付包、标记已发布、记录发布平台和链接、记录表现数据。

作品库按项目与商品两级组织；成片质检结果在作品条目上可见，退回意见可回溯。

## 九、「商品与目标」页面结构（字段与按钮状态规则，D-021 / D-022 / D-023）

本节只记录页面信息结构与状态规则，不实现 UI。

商品资料：

```text
商品图片 *
商品名称 *
核心卖点 *（至少一条，需用户确认）
商品描述
已有文案
```

`*` 为 AI 文案生成的最低输入（D-021）；商品描述与已有文案为可选；商品可以在文案为空时保存（「文案为空」不等于「商品资料不完整」）。

内容偏好（可选，D-022）：

```text
内容偏好（可选）
├── 表达风格
├── 种草角度
├── 期望口播长度
├── 收尾方式
└── 补充要求
```

- ContentBrief 中**没有 `*` 必填项**：内容偏好可以折叠或作为次级区域，用户不打开该区域也能生成文案；
- ContentBrief 可以完全缺失或全部未填写，不得阻止文案生成；
- **目标平台不作为独立字段；目标人群不作为独立字段**；特殊平台或受众要求通过「补充要求」自由文本表达；
- 表达风格默认「自然口语化种草」（支持预设与自定义，除默认值外不固定完整预设目录）；
- 种草角度默认由 AI 根据已确认卖点选择（用户可指定或自定义）；
- 收尾方式默认「自然收尾」（可选「轻度引导」「无收尾引导」或用户自定义；产品界面不使用 CTA 作为主要术语）；
- 期望口播长度仅影响文案篇幅，页面必须显示「不保证最终成片时长」的说明，不固定默认秒数、默认字数或默认长度档位；
- 补充要求为可选自由文本；其中的事实性内容仍受 D-021 事实安全约束。

文案来源：

- AI 根据商品信息生成；
- 使用已有文案。

按钮状态规则：

- **保存商品草稿**：可以在资料未满足 AI 门禁时使用；
- **生成文案**：**只检查 D-021 最低商品事实**——商品名称存在；至少一张商品图片；至少一条卖点；卖点已经由用户确认。不得把任何 ContentBrief 字段（表达风格、种草角度、期望口播长度、收尾方式、补充要求）加入生成按钮的启用条件。不满足时不得调用 LLM，并明确指出缺失字段；
- **进入 VideoPlan**：只有经过人工确认的文案（approved CopyVariant）可用。

文案生成状态展示（D-023）：

用户可见状态：

- 生成中；
- 生成成功并进入草稿；
- 生成失败（可理解的失败状态）；
- 手动重试。

用户不可见或不可编辑：

- API Key；
- Base URL；
- Provider 请求结构；
- thinking 参数；
- Provider 错误原文；
- reasoning_content。

MVP 不提供：

- Provider 设置页；
- 模型选择器；
- V4-Pro 切换；
- BYOK 输入框；
- 第三方中转配置。

页面可以显示友好错误状态，但不得向浏览器泄露 Secret、原始 Provider 响应、内部堆栈或服务端配置。
