## 二、第一阶段主导航（克制原则）

第一阶段主导航应克制，只保留：

```text
首页
项目
素材中心
生产任务
作品库
设置
```

其余长期导航项随 Phase 推进逐步开放，不为未实现能力预留空壳入口。

设置区规划（D-016 / D-020）：

```text
设置
├── 企业信息
├── 成员与基础权限
├── AI 模型
│   ├── 平台默认模型
│   └── 企业自有 API Key（后续，BYOK）
├── Provider 连接
├── Local Agent
├── 内部用量与成本
└── 审计日志
```

设置区**不得出现**：套餐中心、支付、账单、充值、订阅管理（产品不建设面向客户的收费系统，D-016）。Provider 选择仍不进入普通运营主流程，只出现在设置/管理员配置或技术诊断区域（D-013）。

## 三、项目内部五阶段导航

项目内部使用统一的五阶段导航（与 [SAAS_PRODUCT_BLUEPRINT.md](SAAS_PRODUCT_BLUEPRINT.md) 的五阶段一致）：

```text
1 商品与目标
2 文案与质检
3 人物与素材
4 视频方案
5 生成与交付
```

- 阶段导航是项目内的主推进线，展示每阶段的完成度与待办；
- 跨阶段对象（文案、方案、任务）从所属阶段进入，详情页可回溯来源。

## 四、页面职责

| 页面 | 职责 | 主要角色 |
|------|------|----------|
| 首页 | 仪表盘 + 新手引导入口（见第六节） | 运营、管理员 |
| 项目 | 项目列表/创建/成员/交付进度 | 运营、管理员 |
| 项目详情 | 五阶段导航与阶段工作台 | 运营、审核人 |
| 素材中心 | 商品图片、素材、模板的统一管理入口（数字人/声音/场景分域） | 运营 |
| 数字人 | 数字人资产库、创建任务、授权状态 | 运营、管理员 |
| 声音 | 音色库、克隆任务、试听 | 运营 |
| 场景与背景 | 背景资产库与场景字段管理 | 运营 |
| 生产任务 | 运营语言看板 + 任务详情（含证据入口） | 运营 |
| 作品库 | 成片预览、通过/退回、打包交付、发布登记 | 运营、审核人 |
| 发布管理 | 发布平台/链接/表现数据（长期） | 运营 |
| 数据分析 | 成功率、用量、表现复盘（长期） | 管理员 |
| 团队与成员 | 成员、角色、品牌规范、授权（长期） | 管理员 |
| 用量与治理 | 任务数、内部额度、成本、审计（长期，企业内部治理，不面向客户收费） | 管理员 |
| 系统设置 | 组织与项目级配置 | 管理员 |
| 本地执行器 | Agent 列表、配对、健康、登录态、人工接管（技术区） | 执行器管理员 |

## 五、普通运营与技术诊断页面隔离

技术页面：

```text
本地执行器
Provider 连接
诊断日志
失败证据
```

**不得与普通运营主流程混在一起**：

- 运营主导航不出现 Playwright、batch.json、executor 等技术概念；
- 技术状态（执行日志、重试次数、Provider 任务 ID、截图证据、技术状态）收敛在任务详情的次级区域与技术区页面；
- 技术区页面保留完整诊断能力，供技术与执行器管理员使用。

## 六、首页仪表盘

规划指标：

- 本月生成视频数
- 成功率
- 生产中任务
- 待审核文案
- 待审核视频方案
- 待处理失败
- 已启用数字人数
- 最近项目
- 内部额度/任务余量
- 预计节省时间

首次使用新手引导：

```text
1. 创建第一个项目
2. 上传一个商品
3. 生成三版文案
4. 选择数字人与素材（仅展示当前已验证配置项）
5. 生成第一条视频
```

## 七、模板中心（规划）

模板方向：小红书护肤种草、抖音零食带货、淘宝商品讲解、本地生活探店、知识口播、企业介绍、照片说话、双人访谈。

模板可预设：内容结构、时长、视频类型、数字人、声音、背景、字幕、Provider、质检规则。

模板中心入口与模板编辑器属于长期导航，第一阶段不实现。

## 八、作品库（规划）

作品库能力：预览作品、标记通过/退回、批量下载、按商品打包、下载文案、下载封面、下载审核表、导出项目交付包、标记已发布、记录发布平台和链接、记录表现数据。

作品库按项目与商品两级组织；成片质检结果在作品条目上可见，退回意见可回溯。
