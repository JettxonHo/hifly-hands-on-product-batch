## 首要来源

飞影数字人 API V2 文档：`https://api.lingverse.co/hifly.html`

区分两个地址，不得混淆：

- **文档托管域**：`api.lingverse.co`（文档页面所在地址）；
- **实际 API request host**：`hfw-api.hifly.cc`（文档中的 API 请求主机）。

**不得把文档托管地址写成 API base URL。**

## 五层确认状态定义（对应 D-018）

```text
1. API 文档已确认
2. 当前账号权限已确认
3. 真实调用已验证
4. Adapter 已实现
5. SaaS 产品能力已完成
```

每项能力记录以下字段：capability ID、产品目标、API 文档状态、当前账号权限、真实调用状态、Adapter 状态、SaaS 产品状态、已知输入、已知输出、异步任务与状态、授权要求、消耗或积分影响、当前证据来源、未解决问题、最后验证日期。
